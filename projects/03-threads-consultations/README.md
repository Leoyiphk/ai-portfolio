# Project 3: AI Tips Threads → Free Consultations → Freelance Clients

**Category:** Teaching
**Business twin:** Content and social operations for any small team; also the AI enablement job itself.
**Status:** Not started

## Goal
Run an AI-assisted Threads account for Hong Kong and Taiwan audiences (AI tips, prompt recipes, new features) that leads to free consultations, which I use to practise teaching and to earn freelance work.

## Funnel
Posts → profile link → free 30-minute consultation → optional paid freelance work → case study.

## Rules
- A human (me) approves every post before it is published.
- The account states that it is AI-assisted.
- Pick one primary language voice first; test the other later.

## Content pillars (draft)
1. New features explained simply
2. Prompt recipes people can copy
3. Before/after business examples
4. Mistakes and myths

## Folder guide
| Folder / file | What goes in it |
|---|---|
| `content/` | Content calendar and the best-performing posts |
| `playbook/` | Consultation playbook, worksheet, follow-up templates |
| `results/` | Monthly report: posts, engagement, bookings, conversions |
| `approval-workflow.md` | How a post goes from idea to published |
| `failure-log.md` | Mistakes, confusion points, what changed |
| `case-study.md` | Final write-up |

## Metrics
Posts shipped · engagement per pillar · profile clicks · consultations booked · clients converted · top confusion points from consultations.

## Privacy
Client names and details stay in the private vault. Only publish client stories with written permission.

## Before taking paid work
Check the LEGO employment contract on outside work and freelancing.

## Done when
- [ ] Account live with 30+ posts
- [ ] Approval workflow documented
- [ ] 5+ consultations delivered
- [ ] 2-3 client mini case studies (with permission)
- [ ] Consultation playbook written
