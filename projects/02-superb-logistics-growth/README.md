# Project 2: Superb Logistics Growth Engine

**Category:** Growth
**Business twin:** Any small business that gets customers only by word of mouth.
**Status:** Not started

## Goal
Give a referral-only B2B logistics business a way to win new customers: a bilingual website plus SEO content, built with Claude and checked by a human.

## Folder guide
| Folder / file | What goes in it |
|---|---|
| `keyword-research/` | Keyword map (English and Traditional Chinese), search intent notes |
| `content/` | Article drafts, edited versions, content calendar |
| `site-assets/` | Page structure, copy, screenshots of the site |
| `results/` | Monthly metrics and Search Console screenshots |
| `editorial-checklist.md` | The human-in-the-loop checks every article passes |
| `failure-log.md` | What Claude got wrong and the check added |
| `case-study.md` | The final write-up |
